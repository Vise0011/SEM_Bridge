# 문서 수집 및 OCR

공식 HTTPS 기업마당 첨부만 내려받습니다. 모든 리다이렉트는 도메인·포트를 다시 확인합니다.
첨부 크기는 20MiB, PDF는 200페이지 이하로 제한됩니다.

## 지원 형식

- PDF: 페이지별 텍스트, SHA-256, OCR 필요 여부와 보안 표시 저장.
- HWPX: ZIP을 디스크에 풀지 않고 문단 텍스트만 추출. 1,000개 항목·확장 크기 20MB·200개 섹션 제한.
  암호화, 중복 항목, XML 엔티티, 과도한 압축률을 거부합니다. 외부 링크나 매크로는 실행하지 않습니다.
  표 레이아웃과 실제 페이지 배치는 복원하지 않으며 위치는 섹션 인덱스로 표시합니다.
- 바이너리 HWP 등: `FORMAT_CONVERSION_REQUIRED`. 공식 원문을 확인하고 PDF/HWPX 제공 여부를 문의하세요.
  다른 파일을 임의로 같은 공고의 원문으로 교체하거나 단순 확장자 변경을 하지 마세요.

HWPX 추출 구조는 [한컴 공식 설명](https://tech.hancom.com/python-hwpx-parsing-2/)을 참고했습니다.

## OCR 준비

```powershell
python scripts/setup_ocr.py
```

[Tesseract 공식 tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)의 한국어·영어 모델을
고정 커밋과 SHA-256으로 검증해 `data/local/tessdata`에 설치합니다 (Apache-2.0).
이 폴더는 Git/Docker 빌드에서 제외됩니다. 별도 시스템 보안 설정 변경은 필요 없습니다.
[PyMuPDF 공식 OCR 문서](https://pymupdf.readthedocs.io/en/latest/page.html#Page.get_textpage_ocr)의
내장 인터페이스를 사용하므로 별도 Tesseract 실행 파일을 설치하지 않습니다.

서버 실행 후 브라우저를 새로고침하고 공고 상세의 OCR 미리보기를 사용하세요.
저장된 현재 PDF와 다시 내려받은 파일의 해시가 일치해야 실행합니다.
1~3개 페이지, 150dpi, 페이지 렌더링 800만 픽셀, 별도 프로세스 60초 제한입니다.
OCR 중 저장된 원문이 바뀌면 결과를 거부합니다. 서버에서는 동시 OCR 한 건만 실행합니다.

OCR 결과는 오인식 가능성이 있는 참고용이며 저장 원문이나 승인 근거를 대체하지 않습니다.
이미지 문서의 조건은 사람이 공식 문서를 대조해야 하며 현 승인 경로에서는 계속 `UNKNOWN`입니다.

## 수집 기록

로컬 관리 화면에서 한 번에 1~100건을 요청할 수 있고 DB에서 동시 수집을 한 건으로 제한합니다.
개별 첨부 실패는 `PARTIAL`로 남기며, 공고 선택 후 첨부 재수집으로 다시 시도할 수 있습니다.
네트워크/스토리지 오류는 키나 요청 URL 대신 안전한 오류 코드로 기록합니다.
종료 시 진행 작업을 취소하며, 재시작 시 남아 있는 진행 기록을 `INTERRUPTED`로 표시합니다.
자동 스케줄러나 재시작 자동 재수집은 없습니다. 동일 DB를 여러 관리 서버에서 동시에 열지 마세요.
